# 目的

MiniMaxに関する最新情報を週次で収集・整理し、
実運用可能な知識として蓄積する。

特に以下を重視する。

- MiniMax Video
- MiniMax Image
- MiniMax Agent
- MiniMax API
- Video Generation
- Long Video Generation
- Consistent Character
- Multi Character
- Camera Control
- Motion Control
- 360° Video
- Panorama
- VR
- World Model
- ComfyUI Integration
- Workflow Optimization
- Open Source Ecosystem

実運用で再現可能な手法を優先する。

研究段階のみの技術は優先度を下げる。

RTX3060 12GB環境で利用可能な情報を重視する。

# レポート作成方針

以下の情報源を優先して調査する。

- MiniMax公式発表
- GitHub
- HuggingFace
- ComfyUI関連コミュニティ
- X (Twitter)
- Reddit
- YouTube技術解説
- 実利用レポート

過去レポートとの差分を重視する。

単なるニュース収集ではなく、

- 新機能
- 長尺動画生成
- キャラクター一貫性
- 高速化
- VRAM削減
- ワークフロー改善
- 360°・VR関連機能
- 実利用報告

を優先する。

RTX3060 12GBで再現可能な手法を高く評価する。

# ファイル出力

レポートは Reports フォルダへ保存する。

ファイル名:

YYYY-MM-DD_MiniMax_Report.md

例:

2026-10-17_MiniMax_Report.md

# 差分分析

可能な限り前回レポートを参照し、
前週からの変化点を明示する。

以下を区別して記載する。

- 新規情報
- 更新情報
- 継続監視項目
